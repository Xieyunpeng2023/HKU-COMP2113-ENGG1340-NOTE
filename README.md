# HKU-COMP2113-ENGG1340-NOTE

香港大学 COMP2113 / ENGG1340 个人学习笔记，整理 Linux 命令、Bash 脚本与 C++ 入门知识，方便日常查阅和课程复习。

笔记以中文解释为主，保留英文术语，并配有命令及代码示例。

## 内容概览

### Linux

- 目录导航与路径：`ls`、`cd`、`pwd`，相对路径与绝对路径
- 文件与目录操作：`mkdir`、`rmdir`、`rm`、`mv`、`cp`、`touch`
- 文件查看与归档：`cat`、`more`、`tar`
- `vi` 编辑器基础
- 文件权限与 `chmod`
- 文本处理：`grep`、`cut`、`wc`、`sort`、`uniq`
- 文件查找与比较：`find`、`diff`
- 标准输入、标准输出、标准错误、重定向与管道
- 正则表达式基础及命令手册查询

### Shell Script

- Bash 脚本结构与 Shebang
- 输入与输出：`read`、`echo`
- 变量引用、单引号、双引号与转义
- 命令替换
- 字符串长度、切片与替换
- 使用 `let` 进行算术运算
- `if` / `elif` / `else` 条件判断
- `for` 循环

### C++

目前包含基础入门内容：

- 使用 `g++` 按 C++11 标准编译程序
- Hello World 示例
- `#include <iostream>` 与 `std` 命名空间
- `main()` 函数与注释
- 使用 `cout` 和 `endl` 输出内容
