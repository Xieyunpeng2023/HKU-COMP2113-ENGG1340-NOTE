ls命令

列出目录下的内容
ls [-a -l -h] [Linux路径]

ls ： 以平铺的形式，列出当前工作目录下的内容
ls 默认加载Home目录：/home/username
ls -a ： 列出所有的文件，包括隐藏文件(以"."开头的文件)
ls -l ： 以列表（竖向排列）的形式展示内容，并显示更多信息
ls -h ： 以易于阅读的形式，列出文件大小，如K，M，G（通常与-l混合使用）
ls -t ： 以修改时间进行降序排列，便于识别最近修改的文件
可选选项混合使用：
ls -l -a = ls -la = ls -al

cd命令（change directory）

更改当前工作目录
cd [Linux路径]

cd ： 回到Home目录

pwd命令（print work directory）

查看当前工作目录
pwd

相对路径与绝对路径

绝对路径
cd /home/username/Desktop

相对路径
cd Desktop

特殊路径符

.	表示当前目录：cd ./Dsektop
..	表示上一级目录：cd ..  即可切换到上一级目录，cd ../..  切换到上两级目录
~	表示home目录：cd ~/Desktop

mkdir命令（make directory）

mkdir [-p] Linux路径

rmdir命令 （remove directory）

移除目录（文件夹）
rmdir [-r -f] Linux路径
rmdir ： 删除一个空目录
rm -r ： 表示递归地深入遍历任何子目录，并删除所有的文件和目录
rm -f ： 选项可确保不会提示你进行确认操作（如果目标目录中存在大量文件和目录，这个选项就很实用）

cp命令（复制）

将旧文件的内容复制到新文件中，若新文件不存在，则创建一个新文件用于复制；若已存在，怎覆盖所有原内容
cp old-file new-file

cp -r old-dir new-dir ： 此命令用于将目录dir1及其包含的所有子目录和文件，复制到dir2 。如果dir2不存在，会创建一个名为dir2的新目录并复制dir1的内容；若dir2存在，dir1的内容会合并到dir2中 。

tar命令（tape archive）

用于备份文件，磁带归档
tar [option] -f archive.tar[files...]
-f archive.tar ： 指定归档文件的名称
[files...] ： 要打包的文件和目录
-c：创建一个新的归档文件。
-x：解压归档文件。
-t：列出归档文件的内容。
-r：向现有归档文件中追加文件。
-u：仅追加比归档文件中已有文件更新的文件。
-d：找到归档文件中与文件系统不同步的差异。
-A：将一个 .tar 文件追加到另一个 .tar 文件中。

文件权限：
查看权限命令：
ls -l
权限：
-rw-------

第一位：
- ：普通文件
d ：目录

第二至四位：
组权限(read, write, execute)

第五至七位：
创建者权限(read, write, execute)

第八至十位：
其他用户权限(read, write, execute)

修改权限：
chmod [who] [operator] [permissions] filename

who ：
u : user
g : group
o : other
a : all

operator :
+ : add a permission
- : take away a permission
= : set the permission

permission :
r : read
w : write
x : execute

cut命令

返回特定的数据列
它根据-d选项指定的分隔符分割每行内容，并返回-f选项指定的列（字段编号从 1 开始）。
cut -d, -f2 file
-d : 指定的分隔符 （空格也需要打出）
-f : 指定的列（从1开始）

-l :  只返回行数

diff命令

显示file1和file2中不同的行。直观来说，diff会匹配两个文件中相同的行，并显示那些不匹配的行。
将fileA 转化为fileB : 
diff fileA.txt fileB.txt

a （add）：表示在第一个文件的对应行之后添加内容。
c （change）：表示第一个文件的对应行需要修改为第二个文件的对应行内容。
d （delete）：表示在第一个文件中删除对应行。

[m]a[n] :  在fileA的第m行添加fileB的第n行（从第0行开始）
[m]c[n] :  将fileA的第m行修改fileB的第n行（从第0行开始）
[m]d[n] :  将fileA的第m行删除，n表示在 fileB 中对应行的位置（这里是相对位置关系 ） 。

Standard I/O, File redirection and Pipe
标准输入与输出，文件重定向与管道

文件描述符：
0 :  标准输入
1 ：标准输出
2 ：标准报错

> (重定向操作符)
command 1 > file
将该命令的输出保存在文件file内

short form:
command > file

对于已经存在的文件进行重复修改：
command >| file

追加标准输出到file：
command 1 >> file
command >> file

将该命令的报错保存在文件file内：
command 2 > file

将该命令的报错追加在文件file内：
command 2 >> file

命令使用输入fileA，将结果输出给fileB，将报错输出给fileC
command < fileA > fileB 2>fileC

直接进行多个命令的执行
command1 | command2

find命令

find [path] [-name] [-type]

-name filename
-type f :  file
-type d :  directory


grep -E '^...x..x..x' 
-E :  拓展正则表达式
^ :  表示从头开始
$ :  表示从尾部开始
[ ] :  表示与方框内的分别进行匹配（[1-5]，[Hh]）
\ :  取消特殊符号的意义
？
.  :  表示任意单个字符
^...x..x..x  : indicate to match the lines from the beginning, return the line if the 4th, 7th and 10th letters are “x”.
